# AttestChain

**AttestChain** is a reusable, privacy-preserving compliance layer for cross-border remittances built for the Drunix Hackathon (NPCI x Citi).

## Architecture
- **Ledger Engine**: Drunix (Hyperledger Fabric fork)
- **Chaincode**: Node.js (`fabric-contract-api`)
- **Off-Ledger Confidentiality**: Fabric Private Data Collections
- **API Middleware**: Node.js / Express
- **AI Fraud & Structuring Engine**: Python Flask + Scikit-Learn (Isolation Forest)
